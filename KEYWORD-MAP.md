# Keyword map: www.rjinteriors.in

Phase 2 of the SEO brief, written 2026-10-29.

**How to read it**
- **Volume** is unknown for every phrase (no keyword data yet). Rows are ordered by buying intent.
- Each phrase is assigned to exactly one page on this site.
- **Status:** covered / weak (page exists but weak) / new page (needs a new page) / decide (another site already covers it; choose an owner first).

**What this site owns**
- RJIC brand searches.
- Searches for a manufacturer of both GRC and FRP.
- Industry and building-type searches.
- Project case studies.
- How RJIC works.

Product + city, regional and all-India searches belong to the sister sites.
