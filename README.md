# rjinteriors.in

Website for RJ Interiors & Constructions (RJIC), the Bangalore manufacturer of GRC and FRP architectural products behind GRC Bangalore, FRP Bangalore, GRC Chennai and GRC Kochi.

It is a static site. A small build script (`build.mjs`, no dependencies) assembles the pages from shared templates into plain HTML in `dist/`.

## Commands

Requires Node.js 20 or later.

```sh
npm run dev     # build, serve on http://localhost:4173 and rebuild when src/ changes
npm run build   # build into dist/
```

## Where things live

| Path | What it holds |
| --- | --- |
| `src/pages/*.html` | One file per page. The block between `---` lines sets the title, meta description and URL. |
| `src/layout.html` | The shared `<head>`, header and footer wrapper. |
| `src/partials/` | Header, footer, footer call-to-action, map, the GRC/FRP working cycle (`cycle.html`, `cycle-scene.html`), empty projects state, shared SVG patterns. |
| `src/data/site.json` | Company name, phone numbers, emails, brands, navigation and the form endpoint. Change contact details here once and every page updates. |
| `src/data/projects.json` | Verified completed projects (empty for now, see below). |
| `src/drawings/*.svg` | Line drawings of products. Insert one with `{{drawing dome}}`, or `{{drawing panel material=frp}}` to draw it in FRP. |
| `src/assets/` | CSS, JavaScript, fonts (Geologica, self-hosted) and images. |
| `src/root/` | Files copied to the site root, such as `.htaccess`. |

## Motion

All movement comes from how the products are made: drawings are drawn then cast, headings "cure", moulds open, pieces are lifted, supply routes flow. Shared motion lives in the `motion` layer of `site.css` and in `site.js`; the home page adds `home.css`/`home.js`, and the working cycle uses `cycle.css`/`cycle.js`.

- Animations only run when the page has the `motion` class, which the inline script in `layout.html` adds unless the visitor prefers reduced motion. If `site.js` fails to load, the class is removed after 4 seconds so nothing stays hidden.
- Any element with `data-draw` draws the drawings inside it when it scrolls into view. Plates get this automatically, and `h1`/`h2` headings get `data-cure`.
- Home page: a casting stage draws, fills and lifts away one product after another; a conveyor carries pieces as silhouettes through a lit gate, where each shows in colour with its name (speed is `SPEED` in `home.js`); the product grid filters by material; the ordering timeline lights up step by step; sector rows fill on hover; brands light up their place on the map.
- Working cycle (home and Manufacturing pages): seven stages each for GRC and FRP, played while on screen, with a pause button and clickable stages. The scene is generated by a script and saved as `src/partials/cycle-scene.html`; stage timings are the `data-ms` values in `cycle.html`.
- Front matter per page: `headDrawing:` picks the drawing in the dark page header, `ctaDrawing:` the drawing in the ochre call to action, and `styles:` / `scripts:` load extra files from `assets/css` and `assets/js`.

## Adding a verified project

The Projects page shows an empty state until `src/data/projects.json` has entries. Add only projects whose details the client has confirmed:

```json
[
  {
    "id": "unique-url-anchor",
    "name": "Project name",
    "location": "City, State",
    "sector": "Religious",
    "products": "GRC dome and minarets",
    "scope": "Design, mould development, manufacture and supply",
    "completed": "2025",
    "summary": "One or two sentences about the work.",
    "image": { "src": "/assets/img/projects/example.jpg", "alt": "What the photo shows", "width": 1600, "height": 1200 }
  }
]
```

`completed`, `summary` and `image` are optional. Put photos in `src/assets/img/projects/`.

## Enquiry form

With `formEndpoint` empty in `site.json`, sending the form opens the visitor's email app with the enquiry filled in, addressed to the first email in `site.json`. This works without a server and lets visitors attach drawings.

To receive submissions directly instead, set `formEndpoint` to a form service URL, for example a Formspree form (`https://formspree.io/f/xxxxxxx`). The form posts its fields there and shows a confirmation.

## Deploying

Upload the contents of `dist/` to any static host.

- **cPanel or Apache hosting:** upload `dist/` into `public_html`. The included `.htaccess` serves `404.html` for missing pages. It also has an optional HTTPS and `www` redirect, commented out until SSL is active.
- **Netlify, Cloudflare Pages or Vercel:** build command `npm run build`, output directory `dist`.

Canonical URLs, the sitemap and social share tags use `https://www.rjinteriors.in` (`url` in `site.json`).
